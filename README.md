# py-attest

Scaffold and audit Python repositories with a quality gate you can measure: deterministic checks first, an LLM reviewer
whose verdicts are computed by policy (never by the model), and a published eval.

**Status:** pre-alpha — design phase. Start with [`docs/prd.md`](docs/prd.md), [`docs/trd.md`](docs/trd.md) and the
[ADRs](docs/adr/README.md). Implementation plan: [`docs/plan-cc.md`](docs/plan-cc.md).
